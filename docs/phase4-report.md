### 4.3 回测中心指标补齐（Backtest.tsx）

| 类别 | 指标数 | 状态 |
|------|--------|------|
| 收益类 | 5（总收益率/年化收益率/初始资金/最终权益/交易日数） | ✅ |
| 风险类 | 5（最大回撤/最大回撤天数/波动率/下行波动率/VaR(95%)） | ✅ |
| 风险调整类 | 3（夏普比率/索提诺比率/卡玛比率） | ✅ |
| 交易类 | 11（总交易次数/盈利次数/亏损次数/胜率/平均盈利/平均亏损/利润因子/期望收益/最大连胜/最大连败/平均持仓天数） | ✅ |
| 费用类 | 5（总佣金/总印花税/总滑点/总费用/费用比率） | ✅ |
| **合计** | **29 项** | ✅ 按 5 类分组展示 |

**实现说明**：
- 后端 `metrics` 字段直接展示（9 项）
- `trades` 数组聚合得出费用与交易笔数统计（佣金/印花税/滑点/盈利次数/亏损次数/平均盈亏/最大连胜连败）
- `equity_curve` 推导交易日数
- 费用比率 = 总费用 / 初始资金
- 后端未返回的风险指标（最大回撤天数、波动率、下行波动率、VaR、索提诺比率、卡玛比率、期望收益、平均持仓天数）显示 "-"
